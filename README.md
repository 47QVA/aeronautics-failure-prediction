# Aeronautics Failure Prediction

Remaining useful life (RUL) prediction and failure classification for turbofan engines,
using NASA's N-CMAPSS dataset, which drives degradation from real recorded flight-condition
profiles rather than synthetic operating points.

**Status: exploration and baseline modeling complete.** Article and demo are not yet built —
this README will be filled in as those phases land. See `CLAUDE.md` for the full project brief
and phase plan.

## Dataset

NASA N-CMAPSS, subset DS01 (single degradation mode: High-Pressure Turbine efficiency
modifier). See [`data/README.md`](data/README.md) for how to obtain the raw file and the
dataset's internal structure.

Citation: Chao, M., Kulkarni, C., Goebel, K., & Fink, O. (2021). *Aircraft Engine
Run-to-Failure Dataset under real flight conditions*, NASA Ames Prognostics Data Repository.

## Modeling framings

Both are baselined with gradient-boosted trees (XGBoost) on cycle-level features (flight
condition and sensor summary stats, plus a trailing rolling mean per unit -- see
`src/features.py`). Unit-level split: train on units {1,2,3}, tune on {4,5,6}, report on
the held-out test units {7,8,9,10} (`src/splits.py`). Run `python src/train.py` to
regenerate; results below are read directly from `data/processed/phase3_metrics.json`
and `notebooks/02_modeling.ipynb`.

- **RUL regression** (remaining useful life in cycles): test RMSE 10.8, MAE 9.1, mean
  PHM08 score 1.94 (train RMSE 1.8, val RMSE 6.7 -- generalization gap is expected given
  the dataset's small unit count).
- **Binary failure classification** (fails within 20 cycles): test precision 0.87,
  recall 0.63, F1 0.73, ROC-AUC 0.97, at a decision threshold (0.25) tuned on the
  validation set rather than the default 0.5.

These are v1 baselines, not tuned for maximum performance. Optional next step: an
LSTM/CNN comparison (see `CLAUDE.md` Phase 3).
